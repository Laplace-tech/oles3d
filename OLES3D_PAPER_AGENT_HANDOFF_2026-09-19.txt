   (1) research/nnunet/experiment_protocol.json
   (2) research/README.md
   (3) 실제 JSON/CSV/TXT artifact와 checkpoint
   (4) 이 handoff
   (5) 과거 대화

2) observed / inferred / proposed / validated를 구분하라.
   코드가 존재하거나 smoke test가 통과했다는 사실을 연구 효과 입증으로 쓰지 마라.
   Pseudo Dice는 training-patch health signal이며 official validation 성능이 아니다.

   나쁘다고 test로 주장을 구제하거나 연구 질문을 다시 고르면 안 된다.

5) Commit SHA는 이 문서에 고정하지 않는다. 논문에 revision을 적기 직전에
   `git rev-parse HEAD`와 `git ls-remote origin refs/heads/main`의 일치를 확인하라.

[2. 한 문장 연구 질문과 현재 claim]
================================================================================

핵심 연구 질문:
  강한 nnU-Net 3D full-resolution baseline에서 architecture, loss, augmentation,
  cohort, total optimizer updates를 그대로 유지한 채 patch-center sampling만 바꾸면,
  장기별 학습 난도와 오류 유형을 반영하는 P 정책이 동일 update budget에서 더 빠른
  segmentation 학습을 만들 수 있는가?

현재 확인할 primary claim:
  P는 B0보다 independent replication seeds에서 10,000 updates 시점의
  case-first 9-organ macro Dice를 개선한다.

현재 novelty의 정확한 범위:
  - 새 backbone이나 새 loss가 아니다.
  - online train-only observer가 현재 모델의 장기별 Dice deficit과 세 가지 semantic
    error type을 관찰하고, 그 learning state에 따라 guided patch center의 allocation을
    조절하는 sampling policy다.
  - B0/B1/A1/P의 단계적 비교로 candidate pipeline, organ-wise adaptation,
    explicit error-type adaptation의 역할을 분리한다.
  - 학부 연구/단기 학술대회 수준에서 방어 가능한 algorithmic/empirical novelty이지만,
    multi-seed confirmation 전에는 효과가 입증된 novelty라고 쓰지 않는다.

이미 폐기된 주장:
  1. "P가 B0보다 30K final Dice가 높다" -> 폐기.
  2. "P가 overall NSD/HD95를 개선한다" -> 지지되지 않음. 특히 HD95 악화 관찰.
  3. "P가 모든 target에서 wall-clock을 절감한다" -> 지지되지 않음.
  4. "single seed case bootstrap으로 training randomness까지 일반화 가능" -> 금지.

Direction revision의 이유:
  Discovery seed 55254에서 P-B0 macro Dice 차이는 10K에서 +5.1228 percentage
  points, 20K에서 +0.9603 pp, 30K에서 -0.0139 pp였다. 즉 early advantage가
  convergence와 함께 사라지는 형태였으므로 연구 질문을 final superiority가 아니라
  early learning/update efficiency로 좁혔다. 이는 결과를 본 뒤 만든 가설이므로
  seed 55254는 confirmatory evidence에서 제외한다.

[4. Baseline model and common training contract]
================================================================================

Framework:
  nnU-Net v2.8.1, classic 3d_fullres plan.

Network:
  PlainConvUNet, 3D convolution, 6 stages.
  Features per stage: [32,64,128,256,320,320].
  Patch [Z,Y,X]: [160,112,128].
  Batch size: 2.
  Deep supervision: enabled.
  CTNormalization and nnU-Net default augmentation.
  Loss/optimizer/scheduler follow the same nnU-Net trainer lineage for all policies.
  Do not describe P as a new U-Net architecture.

Training budget:
  250 optimizer updates/epoch x 120 epochs = 30,000 updates/run.
  Stage A checkpoints: 10K, 20K, 30K.
  Stage B checkpoints: 5K, 10K, 15K, 20K, 25K, 30K.

Foreground/guided slots:
  nnU-Net foreground setting = 0.33.
  With batch size 2, actual guided/forced slots per batch = 1.
  B1/A1/P replace only this comparable guided slot; the other slot remains random.

Comparator fairness:
  Same frozen data, label map, network, patch size, batch size, loss, augmentation,
  optimizer, scheduler horizon, total updates, evaluation code and inference settings.
  Same seed controls the initialization routine and initial-weight hash is audited.
  The default multi-worker loader is nondeterministic, so augmented batch streams are not
  bitwise identical. Do not claim bitwise/full determinism. All methods use the same loader
  distribution and worker policy.

Runtime environments:
  - Local feasibility: RTX 3060 Ti 8 GB; feasible but little VRAM margin and too slow for
    the full multi-run experiment.
  - Main cloud experiment: RunPod RTX 4090 24 GB.
  - Stage A and Stage B can be on different hosts; update-based primary remains comparable.
  - Wall-clock comparison endpoint was retired on 2026-09-20 before seed-55256 outcomes
    because migration hosts showed materially different CPU quotas and data-wait behavior.
    Timing and observer overhead remain operational diagnostics, not effectiveness claims.


================================================================================
[5. Error semantics and sampling policies]
================================================================================

For organ k, GT mask G_k and prediction mask P_k:

  False negative: G_k AND NOT P_k
  False positive: P_k AND NOT G_k

Boundary tolerance:
  1.5 mm = one isotropic voxel. This is an algorithmic partition parameter, not a clinical
  tolerance claim.

Three mutually exclusive error types:

  interior_miss
    GT interior deeper than the 1.5 mm boundary band, but predicted as another class or
    background. Interpretation: the model misses the organ itself.

  boundary_disagreement
    FN or FP within the physical 1.5 mm band around the GT surface. Interpretation:
    shape/surface localization disagreement.

  exterior_false_positive
    predicted organ outside the GT boundary band. Interpretation: surrounding tissue is
    confused with the organ; detached false-positive components can arise.

Observer/candidate common contract for B1/A1/P:
  - 10 train-only observer patches per epoch.
  - 120 epochs -> 1,200 observer assignments/run.
  - Same seeded train-case permutation and focus-organ rotation.
  - Same candidate definition, refresh cadence, augmentation and bounded reservoir.
  - Reservoir cap: 512 coordinates per organ x error type.
  - Candidate center coordinates use [Z,Y,X].
  - Padding voxels are excluded from error counts/candidates.

Policies:

  B0 — nnU-Net default foreground oversampling
    The original baseline. A foreground-containing patch is forced according to nnU-Net's
    default rule, without OLES3D error candidate pools.

  B1 — matched static control
    Uses the same online semantic-error candidate pipeline as A1/P, but allocates focus
    organs uniformly among organs with candidates. Inside the selected organ, all error
    candidate voxels are pooled and sampled voxel-uniformly. Purpose: isolate the effect of
    introducing the candidate/observer pipeline from adaptive allocation.

  A1 — organ-wise adaptive allocation
    B1 plus organ learning-state adaptation. Observer-patch hard Dice produces difficulty
    d_t(k)=EMA(1-Dice_k), EMA decay beta=0.9. Among organs with candidates:

      p_t(k) = (1-lambda_k)/|K_t|
               + lambda_k * d_t(k) / sum_j d_t(j)

    where lambda_k=0.5. First valid observation directly initializes the organ difficulty.
    After choosing an organ, its three error pools are still pooled/voxel-uniform.

  P — proposed organ x error-type adaptive allocation
    Uses the same organ probability as A1. It additionally tracks, within each organ, the
    EMA of the observed raw share of interior/boundary/exterior errors (beta_r=0.9).
    For available error types r of organ k:

      b_t(r|k) = current candidate-pool voxel fraction
      a_t(r|k) = normalized EMA raw-error share
      p_t(r|k) = (1-lambda_r)b_t(r|k) + lambda_r a_t(r|k)
      p_t(k,r) = p_t(k) p_t(r|k)

    lambda_r=0.5. Before any valid type observation, p_t(r|k)=b_t(r|k), so P cold-starts
    exactly from A1's conditional distribution.

Planned contrasts:
  B0 -> B1 : online candidate/observer pipeline configuration.
  B1 -> A1 : organ-wise learning-state adaptive allocation.
  A1 -> P  : explicit semantic error-type adaptive allocation.
  B0 -> P  : complete OLES3D configuration versus the practical baseline.

[6. Evaluation and statistics]
================================================================================

Primary metric: case-first macro Dice.

For case i and the nine target organs C={1,...,9}:

  Dice(i,k) = 2 TP(i,k) / [2 TP(i,k) + FP(i,k) + FN(i,k)]
  S_i       = (1/9) sum_k Dice(i,k)
  S         = (1/N) sum_i S_i

Each case receives equal weight, and each organ inside a case receives equal weight. Large
organs therefore do not dominate merely through voxel count. Frozen cohort GT-empty is a
protocol violation. A nonempty GT with empty prediction receives Dice 0.

Stage-B confirmatory primary:
  P minus B0 case-first macro Dice at 10,000 updates, evaluated only on independent seeds
  55255, 55256 and 55257 and the same paired 28 validation cases.

Primary success rule:
  1. Mean P-B0 delta is positive in seed 55255.
  2. Mean P-B0 delta is positive in seed 55256.
  3. Mean P-B0 delta is positive in seed 55257.
  4. Paired two-way seed x case bootstrap 95% CI lower bound > 0.

Mandatory qualification:
  Only three replication seeds are planned, so training-seed uncertainty remains limited. Report each
  seed's effect and paired case-bootstrap CI separately. Do not claim stable variance or
  broad generalization to the population of all possible training seeds.

Key secondary endpoints:
  - B0/B1/A1/P Dice at all six Stage-B checkpoints.
  - Normalized trapezoidal AUC of Dice from 5K to 30K, divided by 25K updates.
  - Updates-to-target Dice 0.80, 0.85, 0.90.
  - Per-organ and paired case-level deltas.
  - Exploratory four-smallest-organ macro: adrenal glands, gallbladder, pancreas.
  - Observer overhead, training/inference time, throughput and peak VRAM as operational
    diagnostics only; do not compare policies by elapsed time across migration hosts.
  - At 30K: raw-output NSD@3mm, HD95(mm), empty predictions and detached-component audit.

Target crossing rule:
  Use piecewise-linear interpolation only between the first adjacent observed checkpoints
  bracketing the target. Do not extrapolate. If not bracketed, report "not reached".

Surface metrics:
  NSD tolerance=3.0 mm, corresponding to two 1.5 mm voxels; this is a technical rather than
  clinical tolerance. HD95 uses mm. If prediction is empty and GT nonempty, NSD=0 and HD95
  is undefined; count the failure. Aggregate organ-macro within case, then case mean.

Inference settings:
  nnU-Net sliding-window inference, tile_step_size 0.5, Gaussian weighting and mirroring;
  same settings for every comparator/checkpoint.
